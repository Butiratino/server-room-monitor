# Server-room monitor — ESP32-S3 / BMP280 / Zabbix

Проект для платы Heltec WiFi LoRa 32 V4.3: измеряет температуру и давление BMP280, показывает их на OLED и отправляет данные в Zabbix по TCP Sender.

## Документы

- [Быстрый старт](START_HERE_RU.md) — сборка, прошивка и первоначальная настройка.
- [Техническая записка](docs/TECHNICAL_NOTE_RU.md) — архитектура, кнопки/reset, справочник ошибок, тесты, безопасность и развёртывание на другом ПК.

## Кратко

- Production прошивка выбирается в `main/CMakeLists.txt`: `temperature_monitor.c`.
- Требуется ESP-IDF 6.1.0, target `esp32s3`.
- BMP280: I2C GPIO4/6, адрес 0x76. Встроенный OLED: I2C GPIO17/18.
- При первом запуске или удержании PRG после загрузки Wi‑Fi-настройки задаются через локальную WPA2 setup AP и страницу `http://192.168.4.1`.
- Zabbix host/item names и ограничения настройки описаны в технической записке.

Пароли и локальные настройки Zabbix не хранить в исходниках и не публиковать в логах.
